# Representative visuals

The SVG files in this directory are fictional UI reconstructions made for this public case study. The PNG files are high-fidelity, AI-generated reconstructions based on the supplied production screen references. They are not direct screenshots of the private product.

The visual brand names are deliberately fictional and may differ from the case-study title; this is intentional anonymization.

Approved sanitized screenshots may replace them using the naming and review process in [`docs/SCREENSHOT-GUIDE.md`](../../docs/SCREENSHOT-GUIDE.md).

Do not place raw or unreviewed captures in this directory. The `raw/` and `private/` paths are ignored as an additional safeguard, but originals should preferably remain outside the repository entirely.
